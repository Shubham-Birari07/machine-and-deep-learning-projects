# Health Care Classification System

## Project Overview

Health Care Classification System is an end-to-end supervised machine learning project that predicts a person's health condition based on medical and lifestyle-related features.

The project demonstrates the complete machine learning pipeline, including data preprocessing, exploratory data analysis (EDA), feature engineering, model training, model evaluation, and health condition prediction.

## Problem Statement

Early prediction of health conditions can help support timely medical decisions and improve healthcare outcomes. This project builds a classification model that predicts a person's health condition using patient-related data.
