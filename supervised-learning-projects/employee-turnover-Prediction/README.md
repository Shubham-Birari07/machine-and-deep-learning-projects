# Employee Turnover Prediction

## Project Overview

Employee Turnover Prediction is a supervised machine learning project focused on predicting employee turnover based on employee-related information.

The project demonstrates the machine learning workflow from data preparation and exploratory data analysis to model training, prediction, and evaluation.

## Machine Learning Type

* Supervised Learning
* Classification

## Objective

The objective of this project is to identify patterns in employee data that can help predict whether an employee is likely to leave the organization.

## Workflow

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Preparation
5. Data Preprocessing
6. Train-Test Split
7. Model Training
8. Prediction
9. Model Evaluation

## Business Application

Employee turnover prediction can help organizations:

* Identify employees who may be at higher risk of leaving
* Understand factors associated with employee turnover
* Support employee retention strategies
* Make more data-driven HR decisions
