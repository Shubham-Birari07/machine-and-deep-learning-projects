Real Estate Price Prediction Dataset Documentation

Dataset Name: Real Estate Price Prediction Dataset (Synthetic)

Number of Records: 3000

Number of Features: 14 (13 input features + 1 target variable)

Project Purpose

This dataset is designed for practicing and demonstrating machine
learning regression algorithms. The objective is to predict the median
value of owner-occupied homes (MEDV) using housing, environmental, and
socio-economic features.

Feature Descriptions

1.  CRIM – Per capita crime rate by town.
2.  ZN – Proportion of residential land zoned for lots over 25,000 sq.
    ft.
3.  INDUS – Proportion of non-retail business acres per town.
4.  CHAS – Charles River dummy variable (1 = tract bounds river, 0 =
    otherwise).
5.  NOX – Nitric oxide concentration (parts per 10 million).
6.  RM – Average number of rooms per dwelling.
7.  AGE – Percentage of owner-occupied homes built before 1940.
8.  DIS – Weighted distance to major employment centers.
9.  RAD – Accessibility index to radial highways.
10. TAX – Full-value property tax rate per $10,000.
11. PTRATIO – Pupil-teacher ratio by town.
12. B – Statistical index from the original Boston Housing dataset.
13. LSTAT – Percentage of lower-status population.
14. MEDV – Median value of owner-occupied homes (in thousands of
    dollars). This is the target variable.

Dataset Characteristics

-   Dataset Type: Synthetic
-   Missing Values: None
-   Duplicate Records: None intentionally included
-   Machine Learning Task: Regression

Recommended Algorithms

-   Linear Regression
-   Decision Tree Regressor
-   Random Forest Regressor
-   Gradient Boosting Regressor
-   XGBoost
-   Support Vector Regression (SVR)

Typical Project Workflow

1.  Load the CSV file.
2.  Perform Exploratory Data Analysis (EDA).
3.  Check feature correlations.
4.  Split data into training and testing sets.
5.  Train multiple regression models.
6.  Evaluate using MAE, MSE, RMSE, and R² Score.
7.  Compare model performance.
8.  Use the best model for house price prediction.

Author Note

This dataset was created for educational and portfolio purposes. It is
inspired by the classic Boston Housing dataset, but the records are
synthetically generated for machine learning practice.
