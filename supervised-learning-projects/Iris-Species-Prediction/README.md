# Iris Species Prediction

## Project Overview

Iris Species Prediction is a supervised machine learning classification project that predicts the species of an iris flower based on its measured characteristics.

The project demonstrates a complete classification workflow, including data preparation, exploratory analysis, model training, evaluation, and prediction.

## Machine Learning Type

* Supervised Learning
* Classification
* Multi-Class Classification

## Workflow

1. Load the dataset
2. Explore the data
3. Perform data preprocessing
4. Analyze feature relationships
5. Train the classification model
6. Evaluate model performance
7. Predict iris species
