# ShopSmart Customer Purchase Prediction

## Project Overview

ShopSmart Customer Purchase Prediction is a supervised machine learning project that uses a Decision Tree Classification model to predict customer purchase behaviour.

The project demonstrates a complete machine learning workflow, including data preparation, exploratory data analysis, feature processing, model training, and evaluation.

## Machine Learning Type

* Supervised Learning
* Classification
* Decision Tree Classification

## Objective

The objective of this project is to use customer-related information to predict whether a customer is likely to make a purchase.

## Workflow

1. Data Loading
2. Data Cleaning and Preparation
3. Exploratory Data Analysis
4. Feature Selection
5. Train-Test Split
6. Decision Tree Model Training
7. Model Prediction
8. Model Evaluation

## Model Used

### Decision Tree Classifier

A Decision Tree classifier is used to learn patterns from the training data and classify customers according to their predicted purchase behaviour.
